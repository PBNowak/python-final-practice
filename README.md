# Python Modules 2 and 3 Practice Project

This project contains three Python exercises covering classes and inheritance, exception handling, modules, functions, and user input.

## Reflection

Clear documentation helps a team understand what the code does and why decisions were made. Diagrams can make program structure and relationships easier to understand before coding. Automated tests provide quick feedback and help prevent existing functionality from breaking. Version control gives developers a history of changes and makes it easier to work safely together. Pair or mob programming allows developers to share knowledge and solve problems together, while peer reviews provide another perspective and can catch mistakes early. Together, these practices create shared understanding because knowledge is not kept by only one person. They also support shared code ownership, because everyone can understand, review, improve, and maintain the project.
